# SecureEdge

## Zero-Trust API Gateway & Policy Enforcement Platform

SecureEdge is a security-focused API gateway designed to demonstrate
authentication, authorization, policy enforcement, rate limiting,
audit logging, observability, and secure API design.

## Goals

- Authenticate every request
- Enforce authorization policies
- Implement role-based access control
- Protect APIs using rate limiting
- Maintain security audit logs
- Provide system observability
- Measure API performance
- Containerize the application

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- Redis
- JWT
- Docker
- Prometheus
- Pytest
- Locust
